# demo_robot 公开契约

DemoRobot::contract 是独立的头文件构建目标，只依赖 Roboframe::sdk。
公开声明位于 include/demo_robot/ 和 demo_robot 命名空间，不包含 integration 或组件实现。
当前包含演示产品的配置、输入绑定、输出、诊断、建图及导航任务；它们不属于 SDK。
导航契约是目标/任务状态/路径上下文/速度命令，不暴露 BT 节点状态；BT 通用机制位于 SDK 可选 orchestration，具体树位于产品。

速度回调可由 Controller 工作线程调用，接收者须线程安全、有界且不重入；其余输出仍由命令/Poll owner 调用。
接收者须存活到 Shutdown 完成，SetOutputs({}) 等待在途速度回调结束。

协议适配和 integration 显式依赖此目标。通用组件默认只依赖 SDK，因而不会自动获得这些头文件；
产品定制组件可以显式依赖本目标，但应承认其产品耦合。真正需要跨产品复用的数据/能力契约，
应提炼到共同维护的公共契约或 SDK datatype，而不是让组件依赖产品入口来获取它。

本目录与产品暂处同仓库，未来可连同产品一起交付，也可单独打包。
当前只划清目录、命名空间和 CMake 依赖，不创建子仓库或 submodule。

这里的可获取是构建依赖关系，不是文件访问控制；显式添加头文件路径当然可以包含。
通用组件的默认构建不传播此目录，独立 SDK/组件安装包也不携带它。
当前产品契约随产品源码编译；独立发布的版本与二进制兼容策略尚未实现。
